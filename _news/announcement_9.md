New write-up: <a href="/what-the-agent-may-do.html">What the agent may do</a> &mdash; verified authority envelopes for AI agents in GitHub workflows. A Lean-verified checker decides, for sessions of any length, what a coding agent's session is permitted to do; the model is validated against the action's own code and measured across 16,346 public workflows. <a href="https://github.com/certior/vcore">Code</a>, <a href="https://huggingface.co/datasets/paulibo/vcore-actions-benchmark">benchmark</a>, and <a href="https://huggingface.co/datasets/paulibo/vcore-workflow-envelopes">corpus</a>.
